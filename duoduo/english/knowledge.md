## 二、语法

| 知识点 | 说明 | 掌握度 |
|--------|------|--------|
| 一般现在时（肯定句） | I/You/We/They + 动词原形；He/She/It + 动词+s/es | ❌ |
| 一般现在时（否定句） | don't / doesn't + 动词原形 | ❌ |
| 一般现在时（疑问句） | Do/Does + 主语 + 动词原形? | ❌ |
| 现在进行时（肯定句） | am/is/are + 动词-ing | 🔄 |
| 现在进行时（否定/疑问） | | ❌ |
| There is / There are | 单数用is，复数用are | 🔄 |
| 冠词 a / an / the | an用在元音音素前 | ❌ |
| 代词（主格/宾格） | I/me, he/him, she/her, they/them | 🔄 |
| 形容词性物主代词 | my, your, his, her, our, their | 🔄 |
| 介词 | in, on, under, near, behind, in front of | 🔄 |
| 特殊疑问句 | What, Where, Who, When, How, How many | 🔄 |
