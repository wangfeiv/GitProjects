## 🚀 使用方式

### 录入错题
直接发送以下任意形式：
- 📝 文字：「多多今天数学错了一道题：[题目内容]，她的答案是...，正确答案是...」
- 🖼️ 图片：发送题目照片 + 说明科目和错误情况
- 📝+🖼️ 图文混合：图片 + 文字补充

### 录入薄弱点
- 「多多语文[知识点]掌握不好，需要加强」

### 查询与复习
- 「生成本周复习计划」
- 「多多数学最近哪里薄弱」
- 「多多语文错题汇总」
- 「多多英语知识点哪些还没掌握」

## 🔄 复习状态说明

| 状态 | 说明 |
|------|------|
| ❌ 未掌握 | 刚录入或多次出错，需重点复习 |
| 🔄 练习中 | 已复习，但需继续巩固 |
| ✅ 已掌握 | 多次正确，基本掌握 |
