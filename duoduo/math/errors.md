## 错题 #1：小数的组合与数位

- **日期：** 2026-04-01
- **来源：** 作业
- **原始图片：** 无
- **题目：** 用0、2、4、6四个数字和小数点组成最大的一位小数是____，最小的两位小数是____。
- **多多的答案：** 错误（对"一位小数"、"两位小数"定义理解有误）
- **正确答案：** 最大的一位小数：642.0；最小的两位小数：20.46
- **错因分析：** 对"一位小数"、"两位小数"定义理解错，不能正确排列数字。一位小数=小数点后只有1位，两位小数=小数点后有2位。
- **解题思路：**
  - 一位小数：小数点后1位，剩下三位放整数部分。要最大，大数字从大到小放整数位，0放小数位 → 642.0
  - 两位小数：整数部分两位，0不能放第一位，所以最小开头是2，0放第二位，小数部分剩余数字从小到大 → 20.46
  - 注意：四个数字必须全部用完！
- **知识点标签：** #小数 #数位 #数字排列
- **复习优先级：** ⭐⭐⭐
- **复习状态：** ❌ 未掌握
- **下次复习日期：** 2026-04-11

## 错题 #3：用字母表示数 - 倍数关系

- **日期：** 2026-04-01
- **来源：** 作业
- **原始图片：** 无
- **题目：** 甲数是a，比乙数的6倍多c，乙数是( )。选项：A. 6a+c  B. 6a-c  C. (a+c)÷6  D. (a-c)÷6
- **多多的答案：** 错误
- **正确答案：** D. (a-c)÷6
- **错因分析：** "比乙数的6倍多c"，多出来的要先减去再除以倍数。
- **解题思路：**
  ```
  甲数 = 乙数 × 6 + c
  a = 6 × 乙 + c
  6 × 乙 = a - c
  乙 = (a - c) ÷ 6
  ```
- **知识点标签：** #用字母表示数 #倍数关系 #等式变形
- **复习优先级：** ⭐⭐⭐⭐

## 错题 #5：四舍五入求原数

- **日期：** 2026-04-01
- **来源：** 作业
- **原始图片：** 无
- **题目：** 一个三位小数四舍五入后是4.50，这个三位小数最大是____，最小是____。
- **多多的答案：** 最大写成4.505（错误）
- **正确答案：** 最大：4.504；最小：4.495
- **错因分析：** 4.505四舍五入后变成4.51，不是4.50，所以最大只能是4.504。
- **解题思路：**
  - 最大 → "四舍"得到 → 第三位小数最大是4，不进位 → 4.504
  - 最小 → "五入"得到 → 第三位小数最小是5，进位 → 4.495
- **知识点标签：** #四舍五入 #小数 #逆向思维
- **复习优先级：** ⭐⭐⭐⭐

## 错题 #6：路程公式

- **日期：** 2026-04-01
- **来源：** 作业
- **原始图片：** 无
- **题目：** 一辆汽车每小时行v千米，行了t小时，行驶了____千米。如果路程用s表示，公式是____。如果v=80，t=3，s=____。
- **多多的答案：** 公式书写有误
- **正确答案：** vt；s=vt；s=240
- **错因分析：** 路程公式书写不规范，s=v×t也可写成s=vt
- **解题思路：** 路程=速度×时间 → s=vt，代入v=80,t=3 → s=240
- **知识点标签：** #用字母表示数 #路程公式 #s=vt

## 错题 #7：长方体最大/最小面

- **日期：** 2026-04-01
- **来源：** 作业
- **原始图片：** 无
- **题目：** 小明把一个长9dm、宽7dm、高5dm的长方体纸箱的一个面划破了，需要重新粘贴，最大需要多少平方分米？最小呢？
- **多多的答案：** 错误（最大/最小面判断有误）
- **正确答案：** 最大：63平方分米；最小：35平方分米
- **错因分析：** 长方体有三种不同的面，需要分别计算后比较大小。
- **解题思路：**
  - 长×宽 = 9×7 = 63 dm²
  - 长×高 = 9×5 = 45 dm²
  - 宽×高 = 7×5 = 35 dm²
  - 最大面=最长两边相乘，最小面=最短两边相乘
- **知识点标签：** #长方体 #表面积 #最大最小面
- **复习优先级：** ⭐⭐⭐
